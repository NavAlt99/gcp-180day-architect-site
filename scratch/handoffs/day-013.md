- Cloud SQL High Availability configuration provides synchronous multi-zone replication with automatic failover to a standby instance in a secondary zone.
- Cloud Storage bucket versioning and object lifecycle policies provide point-in-time recovery archives physically isolated from database compute instances.
- Cloud Run containers and standard Compute Engine instances serve stateless HTTP traffic with horizontal auto-scaling and ephemeral local filesystems.
- Memorystore Redis clusters externalize transient session state with low-latency in-memory data structures.
- Stateful Managed Instance Groups (stateful MIGs) preserve persistent disks, static IP addresses, and stateful metadata across VM restarts and recreations.
