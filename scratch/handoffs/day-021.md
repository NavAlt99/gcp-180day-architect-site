- topic-03: Relevance to GCP: Four critical operational boundaries operate at the project layer:
1. IAM Boundary: Project-level IAM bindings (e.g., roles/editor ) apply to all resources inside the project, but do not extend to neighboring projects unless granted at an ancestor folder.
2. Network Boundary: Virtual Private Cloud (VPC) networks are project-scoped entities. Cross-project network traffic requires Shared VPC (where service projects attach to a centralized host project's subnets) or VPC Network Peering.
3. Billing Boundary: Each project links to exactly one Cloud Billing account. Multiple projects can share a billing account, but a single project cannot split costs across multiple billing accounts directly.
4.
