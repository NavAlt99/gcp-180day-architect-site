A single RAG request path

A grounded-answer path ingests permitted documents, chunks them, creates embeddings or another index representation, retrieves candidates under the caller's permissions, optionally reranks them, and asks a fixed model/prompt to answer with citations. Every stage can reduce recall, add latency or leak data.
